# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Lunarbase-Lab/lunarbase-sdk/security/advisories/new).
Do not open a public issue or disclose exploit details before a fix is
available.

Include the affected package and version, impact, reproduction steps, and any
suggested mitigation. Remove private keys, access tokens, RPC credentials, and
deployment secrets from the report.

## Operational responsibility

Integrators must verify deployment addresses and runtime-code hashes, protect
checkpoint storage and registry credentials, and route quote traffic only to
ready instances.
